## Om Prosjektet
Oppgaven var å utvikle et Java-program for en skraphandler, med import av kjøretøydata fra fil til MySQL og en meny for å hente informasjon fra databasen. Arbeidet omfattet arv, polymorfi, innkapsling, filhåndtering og databasekommunikasjon med JDBC.
